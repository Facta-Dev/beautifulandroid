# /research

## Delegate

Delegate to the **research** skill. Activate when a question about `<app>`
has to be answered from authoritative sources and the answer is worth keeping:
an API contract to implement against, a version behaviour that decides a
design, a claim that will land in a document or a commit message.

Steps:

1. Frame the question and the scope of the investigation.
2. Delegate the reading to a background agent with a fresh context window.
3. Require primary sources only, official documentation, the source code, the
   specification, and a citation for every claim.
4. Save the brief as one Markdown file where the repository already keeps such
   notes, and say where it went.
5. Report the path, the findings with their citations, and what could not be
   verified.
